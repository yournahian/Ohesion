Ohesion — 100% Component-Driven Discord Engine

Ohesion is designed so neither members nor admins ever need to type long slash commands or memorize complex parameters. Everything runs via 37 Interactive Buttons, Dropdown Menus, and Discord Modals.

🖱️
Visual Architecture:
• Member Hub (`#cohesion-hub`): 12 interactive buttons organized across 3 action rows.
• Admin Dashboard (`/admin`): 25 visual management buttons organized across 7 functional rows.

🚀 1-Click Setup

Run `/setup` once as an administrator. The bot automatically creates:

  • 📁 COHESION HQ — Organized category with proper permissions.
  • #cohesion-hub — Deploys the interactive 12-button Member Dashboard.
  • #cohesion-quests — Dedicated channel for social raids and Twitter quests.
  • #cohesion-levels — Dedicated level-up announcements channel (keeps general chat clean!).
  • #cohesion-logs — Private administrative audit trail.

🧭 Member Hub (Part 1: Daily, Ranks & Economy)

Row 1: Primary Action Buttons
🎁 Claim Daily 🏆 Leaderboard 🎟️ Raffles 🛒 Marketplace 🔨 Auctions
ButtonWhat It Does & User Experience
`🎁 Claim Daily` 1-click daily points claim. Awards consecutive day streak bonus multipliers to boost wallet and rank.
`🏆 Leaderboard` Pops up an ephemeral view of the top 10 community members ranked by Points (CP), XP, or Quests.
`🎟️ Raffles` Opens the active raffles menu. Members can buy tickets (1x, 5x, 10x, Custom) with points to win prizes.
`🛒 Marketplace` Opens an interactive dropdown menu to purchase Discord roles and server perks with points.
`🔨 Auctions` Opens live auctions. Members bid points with instant escrow and automatic refunds if outbid.

🧭 Member Hub (Part 2: Wallets, Socials & Sync)

Row 2: Connections & Profile Sync
👛 12-Chain Wallet 🐦 Change X 🌐 Connect Socials 🔄 Refresh
ButtonWhat It Does & User Experience
`👛 12-Chain Wallet` Opens a modal form to link an EVM (Ethereum, BSC, Base, Arbitrum) or Solana payout address for prize distributions.
`🐦 Change X` Opens a modal asking for the user's Twitter / X handle. Enables instant 1-click verification on tweet quests.
`🌐 Connect Socials` Allows members to connect their YouTube, TikTok, and CoinMarketCap accounts for cross-platform quests.
`🔄 Refresh` Instantly recalculates and updates personal XP, Level progress bar, and Point balance on the card.

🧭 Member Hub (Part 3: Referrals, Raids & Tickets)

Row 3: Growth & Support Buttons
👥 Invite Codes & Referrals 🚀 Promote My Tweet (Raid) 🎫 Support Ticket
ButtonWhat It Does & User Experience
`👥 Invite Codes & Referrals` Generates a personal invite code. Shows how many members joined with your code and your earned bonus points.
`🚀 Promote My Tweet (Raid)` Community-funded tweet raids! Members spend their earned points to launch a raid on their own tweet.
`🎫 Support Ticket` Opens a modal for Subject and Description, then creates a private #ticket-user channel. Staff role is automatically tagged (if configured). Once closed, staff can click `[ 🔓 Reopen Ticket (Staff Only) ]` which restores messaging and mentions the creator!

⚙️ Admin Control Center (Row 1: Quests, Raffles & Auctions)

Row 1: Campaign Creation Buttons
📢 Tweet Quest 🌐 CMC & Video Quests 📝 Quest Drafts 🎟️ Create Raffle 🔨 Create Auction
ButtonAdmin Action & Result
`📢 Tweet Quest` Opens visual modal: Tweet URL, Points reward, Expiration hours, Tag requirement, and Call to action.
`🌐 CMC & Video Quests` Modal form to drop YouTube video, TikTok, or CoinMarketCap gravity quests into #cohesion-quests.
`📝 Quest Drafts` View, edit, or launch previously drafted quests without retyping URLs.
`🎟️ Create Raffle` Interactive form: Prize title, Ticket price (CP/XP), Max tickets per user, Duration, and Winner count.
`🔨 Create Auction` Interactive form: Auction item, Starting bid, Min bid increment, Duration, and Description.

⚙️ Admin Control Center (Row 2: VC, Shop & Rewards)

Row 2: Member Rewards & Shop Management
🎙️ VC Snapshot 🎁 Reward Member / Role 🛒 Add Shop Item 📜 Shop Orders 🎲 Draw Winner
ButtonAdmin Action & Result
`🎙️ VC Snapshot` 1-click attendance taker. Scans all active voice channels and awards points & XP to all connected listeners.
`🎁 Reward Member / Role` Manually credit or deduct Points / XP from an individual user or all members holding a specific Discord role.
`🛒 Add Shop Item` Modal form: Item name, Point price, Stock limit, and auto-granted Discord Role upon purchase.
`📜 Shop Orders` Displays order log of all marketplace purchases and auto-role delivery statuses.
`🎲 Draw Winner` Instantly concludes an active raffle, selects random winning ticket(s), and exports a CSV roster to staff.

⚙️ Admin Control Center (Row 3: Auto-Track, Roles & Decay)

Row 3: Automation & Economy Health
🤖 Auto-Track X Feeds ⚡ Announcement Reacts 🎖️ 5-Tier Milestone Roles 🔥 Weekly Inflation / Decay
ButtonAdmin Action & Result
`🤖 Auto-Track X Feeds` Monitors official Twitter accounts. When a new tweet is posted, bot automatically drops a raid quest!
`⚡ Announcement Reacts` Configure channels where reacting to announcements awards bonus points (e.g. 10 CP per reaction).
`🎖️ 5-Tier Milestone Roles` Assign automatic Discord roles when members reach Level 5 (Bronze), 10 (Silver), 20 (Gold), 30 (Diamond).
`🔥 Weekly Inflation / Decay` Applies a weekly percentage burn (e.g. 5% or flat 50 CP) to inactive balances to prevent point hoarding.

⚙️ Admin Control Center (Row 4: Season Reset)

Row 4: Seasonal Reset Controls
🔄 Season Reset

`🔄 Season Reset` allows admins to conclude a competitive season. It archives final leaderboards, wipes current point balances, and starts a fresh competitive cycle while preserving user levels and historical message archives.

⚙️ Admin Control Center (Row 5: Quizzes, Polls & Battles)

Row 5: Community Engagement & Minigames
🧠 Create Quiz ⚡ Live Quiz Show 📊 Create Poll ⚔️ Chaos Clash 🎙️ Voice Studio Notes
ButtonAdmin Action & Result
`🧠 Create Quiz` Launch a solo interactive quiz challenge where members answer questions for rewards.
`⚡ Live Quiz Show` Starts a Kahoot-style real-time community trivia showdown with live scoreboards.
`📊 Create Poll` Modal form to launch community polls with interactive button choices and live visual percentage bars.
`⚔️ Chaos Clash` Launches a battle tournament lobby where members join as fighters and spectators wager points on winners.
`🎙️ Voice Studio Notes` Generate audio recordings and AI summary notes from community calls, AMAs, and voice events.

⚙️ Admin Control Center (Row 6: Modes, Telegram & Exports)

Row 6: Core System Controls
⚙️ Server Mode & Modules ✈️ Telegram Settings 📢 Level-Up Channel 📥 Export Userlist / CSV
ButtonAdmin Action & Result
`⚙️ Server Mode & Modules` Select from 4 Presets, toggle any of the 11 modules via checkboxes, or click `[ 🎫 Ticket Auto-Tag ]` to choose which staff role is auto-tagged on new tickets (or disable it)!
`✈️ Telegram Settings` Configure and manage the Telegram group bridge with @OhesionBot.
`📢 Level-Up Channel` Choose where level-up messages are routed (e.g. #cohesion-levels) or select ⛔ Disabled to silence chat announcements!
`📥 Export Userlist / CSV` Opens the Unified Export Dashboard: Full Server CSV with Date-Range filters, Single Member Dossiers, and Sync Message History (50,000+ messages)!

⚙️ Admin Control Center (Row 7: Cohesion Shield & Channel Links)

Row 7: Community Security & Link Filter
🛡️ AutoMod & Shield

Clicking `🛡️ AutoMod & Shield` opens the master security deck:

  • Toggles: Anti-Link, Anti-Invite, and Rapid Message Flood Spam.
  • Custom Banned Words: Modal form to input scam phrases and rival project names.
  • Punishment Escalation: Choose Warn Only, Warn + Timeout (10m), or 3-Strike Auto-Ban.
  • `[ 🔗 Custom Channel Links ]`: Dropdown menu to pick any channel and set its custom link rule:
    • `[ 🛡️ Set Allowed Links ]`: Modal where you enter approved domains (e.g. x.com, twitter.com, rialo.io). Only approved links pass; all others get deleted!
    • `[ 🟢 Allow All ]`: Unrestricted links allowed (e.g. media channels).
    • `[ 🔴 Block All ]`: Strictly zero links allowed (e.g. general chat).
    • `[ 🗑️ Reset to Default ]`: Reverts channel to server default policy.

🗺️ Master Interaction Map (How Everything Connects)

End-to-End Visual Loop

1. Admin Setup: /setup ➔ Deploys `#cohesion-hub` and `#cohesion-quests`.
2. Admin Customization: Click [ ⚙️ Server Mode & Modules ] to pick preset or toggle modules on/off. Click [ 🛡️ AutoMod & Shield ] to set per-channel link whitelists.
3. Member Daily Engagement: Members visit `#cohesion-hub` ➔ Click [ 🎁 Claim Daily ] ➔ Click [ 👛 12-Chain Wallet ] and [ 🐦 Change X ].
4. Quest Drops & Raids: Admin clicks [ 📢 Tweet Quest ] ➔ Member clicks [ 🚀 Submit Quest ] on card ➔ Instant CP & XP.
5. Spending Rewards: Members click [ 🎟️ Raffles ], [ 🔨 Auctions ], [ 🛒 Marketplace ], or [ ⚔️ Chaos Clash ] to spend points.
6. Support & Safety: Members click [ 🎫 Support Ticket ] for private staff channels. Cohesion Shield auto-moderates spam and enforces link whitelists.
7. Analytics: Admin clicks [ 📥 Export Userlist / CSV ] to download full server CSV data with date filters.
