🚀 1-Click Server Setup

Setting up Cohesion takes literally 5 seconds with zero manual channel or permission configuration required.

Discord Admin Command
/setup

What happens automatically when you run /setup:

  1. Category Creation: Creates a clean 📁 COHESION HQ category with tailored permission overrides.
  2. Dedicated Channels:
    • #cohesion-hub — Master interactive member control center.
    • #cohesion-quests — Dedicated social raids and Twitter quest channel.
    • #cohesion-levels — Dedicated level-up announcements channel (stops general chat spam!).
    • #cohesion-logs — Private administrative audit trail.
  3. Interactive Hub Deployment: Spawns the persistent interactive dashboard in #cohesion-hub with direct buttons for Quests, Profile, Daily Claim, Shop, Tickets, Leaderboards, and Admin Feature Controls.

🛡️ Cohesion Shield (AutoMod & Community Security)

Cohesion Shield operates in real-time on every chat message, inspecting content before allowing it to post.

Access Shield Dashboard
/admin ➔ Click [ 🛡️ AutoMod & Shield ]

Core Shield Modules:

  • 🔗 Anti-Link Protection: Server-wide detection and automatic instant deletion of unapproved URLs and hyperlinks.
  • 🚪 Anti-Invite Blocker: Auto-detects and removes rogue Discord invite links (e.g. discord.gg/...) from competitors or spammers.
  • ⚡ Rapid Message Flood Control: Detects burst spamming (>4 messages in 3.5 seconds) and identical repetitive message copy-pasta.
  • 📝 Custom Banned Keywords: Filter out specific scam words, phishing phrases, or rival project tags.

🔗 Fully Customizable Per-Channel Link Rules

Unlike basic bots that only offer an on/off switch, Cohesion allows you to customize exact link permissions for every single channel in your server!

🌟
Example Real-World Community Setup:
• #twitter-raids ➔ Allow only x.com, twitter.com
• #media-creators ➔ Allow only youtube.com, twitch.tv
• #official-links ➔ Allow only your official project website (e.g. rialo.io)
• #general-chat ➔ Block all links strictly!

How to Configure Per-Channel Links in 30 Seconds:

  1. Run /admin ➔ Click `🛡️ AutoMod & Shield`.
  2. Click the green button `[ 🔗 Custom Channel Links ]`.
  3. Select your target channel from the native Discord Channel Select Menu.
  4. Choose its rule:
    • `[ 🛡️ Set Allowed Links ]` — Type or paste multiple allowed domains (e.g. x.com, youtube.com, rialo.io). Approved links pass cleanly; unapproved links get auto-deleted with a warning!
    • `[ 🟢 Allow All ]` — Unrestricted links permitted in this channel.
    • `[ 🔴 Block All ]` — Strictly zero links allowed.
    • `[ 🗑️ Reset to Default ]` — Reverts to server default policy.

⚖️ Punishment Escalation Policy

Choose how aggressively Cohesion Shield responds when a member violates community rules:

  • ⚠️ Warn Only: Deletes the offending message and posts an 8-second self-deleting friendly warning.
  • ⏱️ Warn + Timeout: Warns on strike 1; automatically mutes/times out the offender for 10 minutes on strike 2+.
  • 🔨 Full Escalation (Recommended):
    • Strike 1: Instant message delete + warning.
    • Strike 2: 10-minute Discord Timeout.
    • Strike 3: Automatic Ban from the Discord server.

*Strikes automatically expire after 1 hour of clean behavior. Admins can click [ 🔄 Reset Strikes ] anytime.

🎯 Social Quests & Raids (Twitter / X)

Reward your community members for liking, retweeting, following, and commenting on your social media posts.

Publish Tweet Quest
/tweet <tweet_url> [points] [expire_hours] [tag] [custom_text]

How Members Complete Quests:

  1. Members connect their Twitter handle once via /connect-twitter or in #cohesion-hub.
  2. When an admin publishes a tweet quest in #cohesion-quests, an interactive quest card appears with [ 🚀 Submit Quest ].
  3. Members click the button, paste their response or proof, and instantly receive their Points & XP!
  4. Every completed quest is permanently logged in #cohesion-logs.

🎫 Native Discord Support Tickets

100% native Discord ticketing system without broken external web dashboards.

Ticket Lifecycle:

  1. Member clicks `[ 🎫 Support Ticket ]` in #cohesion-hub.
  2. A native Discord Modal opens asking for Subject & Issue Description.
  3. The bot creates a private channel #ticket-username-1234 under 🎫 SUPPORT TICKETS visible only to the member and staff.
  4. The ticket channel contains interactive control buttons:
    • `[ 🔒 Close Ticket ]` — Archives the ticket and revokes member typing permission.
    • `[ 📄 Save Transcript ]` — Generates a downloadable text transcript of all messages and attachments.
    • `[ 🗑️ Delete Channel ]` — Safely cleans up the channel.

📊 Member Intelligence & CSV Data Export

Access full community analytics, member dossiers, and enterprise-grade CSV exports directly from Discord.

Open Export Dashboard
/admin ➔ Click [ 📊 Export Users & Audit ]

Export Features:

  • Full Server Export (CSV): Exports 100% of server members with Discord ID, Username, Messages Sent, Level, XP, Points, Wallet Address, Twitter Handle, and Join Dates. Includes unified Date-Range filtering (Start Date & End Date).
  • Single Member Dossier: Inspect any individual member's exact statistics, top channels where they chat, and download their personal CSV report.
  • Channel Message Audit: Run an audit on any specific channel to see who chats the most, with an instant CSV leaderboard download.
  • Lifetime Message History Sync: Scans all past channel messages to backfill historical message counts with 100% accuracy matching Discord Search.
